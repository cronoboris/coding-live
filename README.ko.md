# coding live

[English](README.md) · 한국어

**AI 코딩 에이전트를 스포츠 중계처럼 보세요.**

코드는 읽지 마세요. 그냥 보세요.

https://github.com/user-attachments/assets/d24ae915-1394-4061-b78c-9a0c16770842

코딩을 하나의 스포츠 종목으로 보고, 지금 돌고 있는 코딩 에이전트를 실시간으로 중계합니다.\
같은 프로젝트 폴더에서 일하는 에이전트들(Claude Code와 Codex를 같이 돌리는 경우 등)은 한 경기의 선수로 묶여 함께 중계됩니다.

코드를 읽지 못해도 "지금 어디까지 했는지, 막혔는지, 내가 정해 줘야 할 게 있는지"를 알 수 있게 하는 것이 목표입니다.

### 보인다

- **파일 지도**\
  프로젝트 파일이 트리맵으로 펼쳐지고, 모든 파일 이름이 보입니다.\
  선수가 지금 있는 파일이 가장 크게 보이고, 최근에 만진 파일은 천천히 작아집니다.\
  선수 칩이 작업 중인 파일로 옮겨 가며 단계(읽기·작성·테스트·실패 후 수정·통과)를 보여 줍니다.\
  두 선수가 같은 파일을 고치면 따로 표시됩니다.

- **여러 선수, 보조 선수**\
  서브에이전트는 자기를 보낸 선수 아래에 "engine ↳ 다리오 아무데이의 보조 · heavy-worker"처럼 보조 선수로 붙습니다.

- **위젯**\
  항상 맨 위에 떠 있는 작은 창입니다.\
  터미널 옆에 붙여 두면 지금 뛰는 경기를 따라갑니다.

### 이해된다

- **캐스터 자막**\
  에이전트의 실행 기록을 규칙대로 옮깁니다.\
  모델을 쓰지 않으므로 내용을 지어내지 않습니다.

- **더보기**\
  중계 줄마다 에이전트가 쓴 도구와 명령이 무슨 일을 하는지 한 단계씩 쉬운 말로 풀어 줍니다.

- **AI 해설(선택)**\
  결정적 장면에서만 작은 모델이 캐스터와 해설위원의 2인 중계를 합니다.\
  해설은 사실만 말하고, 선수(에이전트)의 주장은 "선수 말로는…"처럼 출처를 밝힙니다.

### 잡아낸다

- **37가지 결정적 장면**\
  첫 테스트 실패, 실패 직후 테스트 고쳐 쓰기, 연속 실패, 혼자 정한 기준, 테스트 건너뛰기, 검사 줄이기, 실패 덮기(`|| true`), 되돌리기 어려운 명령 등을 규칙으로 잡아냅니다.\
  장면마다 켜고 끌 수 있습니다.

- **배움 카드**\
  무슨 일인지 일상 비유로, 왜 중요한지, 정당한 경우와 꼼수를 구분하는 법을 알려 줍니다.\
  에이전트에게 그대로 붙여 넣을 질문(복사 버튼)도 함께 나옵니다.\
  AI 없이도 동작합니다.

- **알림과 경기 종료 리포트**\
  창을 닫아도 중요한 장면을 알려 줍니다.\
  경기가 끝나면 공개된 계산식으로 매긴 평점과 사용자가 직접 확인할 것 하나를 남깁니다.

선수 이름은 모델 회사에 맞춘 AI 업계 인물 말장난 이름(예: 다리오 아무데이, 샘 알트탭)입니다.\
재미를 위한 패러디이며 실제 인물과 관계없습니다.\
설정에서 일반 이름으로 바꿀 수 있습니다.

## 설치

터미널 없이 쓰는 데스크톱 앱입니다.\
[Releases](https://github.com/cronoboris/coding-live/releases)에서 내 컴퓨터에 맞는 파일을 받아 설치하세요.

| 컴퓨터 | 받을 파일 |
|---|---|
| 맥 (M1~M4 등 애플 실리콘) | `coding-live-…-mac-arm64.dmg` |
| 맥 (인텔) | `coding-live-…-mac-x64.dmg` |
| 윈도우 | `coding-live-…-win-x64.exe` |
| 리눅스 (우분투·데비안) | `coding-live-…-linux-amd64.deb` (더블클릭하면 앱 센터로 설치) |
| 리눅스 (그 밖) | `coding-live-…-linux-x86_64.AppImage` (파일 속성에서 실행 허용을 켜야 열림) |

아직 유료 서명 인증서가 없어서 처음 열 때 한 번 확인 창이 뜹니다.

- **맥**\
  dmg를 열고 앱을 응용 프로그램 폴더로 끌어 놓은 뒤 실행하세요.\
  "확인되지 않은 개발자" 창이 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 맨 아래 **그래도 열기**를 누르세요.

- **윈도우**\
  "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

실행하면 중계석 창과 작은 **위젯**이 함께 뜹니다.\
위젯은 항상 맨 위에 떠 있으므로 에이전트를 돌리는 터미널 옆에 붙여 두면 좋습니다.\
지금 뛰고 있는 세션을 자동으로 따라가며(다른 경기를 고를 수도 있습니다), ⤢를 누르면 그 경기를 큰 화면으로 엽니다.\
위젯 위치는 기억됩니다.

창을 닫아도 메뉴 막대(윈도우는 작업 표시줄 오른쪽 트레이)에 남아서 알림을 계속 받습니다.\
트레이 메뉴의 **위젯 보기**로 위젯을 켜고 끌 수 있습니다.\
**로그인하면 자동으로 켜기**를 고르면 컴퓨터를 켤 때마다 자동으로 실행됩니다.\
완전히 끄려면 트레이 메뉴의 **coding live 끄기**를 누르세요.

### 개발자용 실행

```sh
npm install
npm run app                 # 데스크톱 앱
node bin/coding-live.mjs    # 브라우저로 보기 (--port, --mic auto|anthropic|openai|google|ollama|compatible|off, --no-open)
```

설치 파일 만들기: `v0.1.0` 같은 태그를 올리면 GitHub Actions가 맥·윈도우·리눅스 설치 파일을 만들어 Releases에 올립니다.

## 붙는 에이전트

에이전트를 고치지 않고, 각 에이전트가 디스크에 남기는 세션 기록을 읽습니다.\
에이전트마다 어댑터가 기록을 공통 이벤트(`src/core/events.mjs`)로 바꾸고, 중계 엔진(`src/core/match.mjs`)은 하나입니다.

| 에이전트 | 기록 위치 | 상태 |
|---|---|---|
| Claude Code | `~/.claude/projects/*/*.jsonl` (`CLAUDE_CONFIG_DIR`) | 지원 |
| Codex CLI | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` (`CODEX_HOME`) | 지원 |
| Gemini CLI | `~/.gemini/tmp/<project>/chats/session-*.jsonl` (`GEMINI_CLI_HOME`) | 지원 |
| Pi | `~/.pi/agent/sessions/*/*.jsonl` (`PI_CODING_AGENT_DIR`) | 지원 |
| omp (oh-my-pi) | `~/.omp/agent/sessions/*/*.jsonl` (`PI_CONFIG_DIR`, XDG, 프로필) | 지원 |
| 믹스독 | `~/.mixdog/data/sessions/*.json` + 진행 중인 턴 체크포인트 (`MIXDOG_HOME`, `MIXDOG_DATA_DIR`) | 지원 |

Codex·Gemini·Pi·omp·믹스독 어댑터는 각 에이전트의 공개 소스(Codex rust-v0.162, Gemini CLI 0.63, Pi 1.1, omp 18.10, mixdog 1.1)에서 확인한 기록 형식으로 만들었습니다.\
테스트는 그 형식으로 만든 합성 기록으로 실행합니다.\
실제 기록에서 다르게 보이는 부분이 있으면 이슈로 알려 주세요.

서브에이전트(보조 선수)는 Claude Code·Codex·omp·믹스독에서 표시됩니다.

## 설정

왼쪽 위 톱니바퀴(⌘, / Ctrl+,)에서 바꿀 수 있습니다.\
바꾸는 즉시 저장됩니다.

- **일반**\
  언어(시스템·한국어·English, 시스템이면 컴퓨터 언어가 한국어일 때만 한국어), 테마(시스템·다크·라이트), 선수 이름(말장난·일반), 로그인하면 자동으로 켜기, 켤 때 창 숨기기

- **에이전트**\
  에이전트별로 켜고 끄기, 기록 폴더 직접 지정, 찾은 경기 수

- **해설**\
  프로바이더와 프로바이더별 연결 방법·모델·API 키·테스트, 새 경기에서 자동으로 켜기, 말투(매운맛·순한맛), 도구·명령 설명, 초보자 설명(자세히·짧게·끄기), 경기당 해설 한도(10~100 또는 무제한), 쓴 비용

- **장면**\
  어떤 결정적 장면을 잡을지 하나씩, 또는 묶음(테스트·의심 행동·서브에이전트·파일·명령·진행 상황·사용자 확인) 단위로 켜고 끕니다.

- **알림**\
  창을 닫아도 트레이에서 지켜보다가 임의 기준 선택·꼼수 의심 장면·연속 실패·오랜 정적·경기 종료를 알려 줍니다.\
  종류별로 켜고 끌 수 있습니다.

- **위젯**\
  보이기, 항상 맨 위에, 따라갈 경기(자동·직접), 투명도, 위치 초기화

- **개인정보**\
  AI 해설에 에이전트가 한 말을 보낼지 여부

## 해설 마이크 설정

**설정 → 해설**에서 프로바이더를 고르고, 카드를 펼쳐 연결 방법과 모델을 정합니다.\
카드마다 **테스트** 버튼이 있어서 고르기 전에 실제로 한 번 불러 볼 수 있습니다.\
연결이 안 되면 이유(설치 안 됨·로그인 필요·키 오류·모델 이름·크레딧 부족·Ollama 꺼짐 등)를 알려 줍니다.

| 프로바이더 | 연결 방법 | 모델 |
|---|---|---|
| Anthropic | Claude Code 로그인, 또는 API 키(`ANTHROPIC_API_KEY`) | Haiku 5.5(추천)·Sonnet 5.5·Opus 5.5·Fable 5.1·직접 입력 |
| Google | Gemini CLI 로그인, 또는 API 키(`GEMINI_API_KEY`) | Gemini 2.5 Flash(추천, 무료 사용량 있음)·Flash-Lite·Pro·직접 입력 |
| OpenAI | Codex 로그인, 또는 API 키(`OPENAI_API_KEY`) | Codex 기본 모델·GPT-5 mini·nano·GPT-5·직접 입력 |
| Cursor | Cursor CLI 로그인(`agent login`), 또는 `CURSOR_API_KEY` 환경 변수 | CLI 기본 모델·직접 입력 |
| GitHub Copilot | Copilot CLI 로그인(`copilot`에서 `/login`) | claude-haiku-4.5(추천)·직접 입력 |
| Qwen | Qwen Code 로그인(`qwen`을 한 번 실행) | qwen3-coder-plus(추천)·직접 입력 |
| opencode | opencode 로그인(`opencode auth login`) | CLI 기본 모델·직접 입력(`provider/model`) |
| Amp | Amp CLI 로그인(`amp`을 한 번 실행, 실행 모드는 유료 크레딧) | CLI 기본 모델 |
| Grok | Grok CLI 로그인(`grok login`) | CLI 기본 모델·직접 입력 |
| Ollama | 내 컴퓨터(기본 `http://127.0.0.1:11434`), 크레딧 없이 무료 | 설치된 모델 중에서(예: `ollama pull gemma3`) |
| OpenAI 호환 서버 | 서버 주소 + 선택 API 키 (LM Studio `http://127.0.0.1:1234/v1`, OpenRouter 등) | 서버의 모델 이름 |
| OpenCode Go | API 키(`OPENCODE_API_KEY`), `https://opencode.ai/zen/go/v1` | glm-5.2(추천)·직접 입력; claude는 Messages, gpt는 Responses, 나머지는 Chat Completions |
| OpenRouter | API 키(`OPENROUTER_API_KEY`), `https://openrouter.ai/api/v1` | openrouter/auto(추천)·직접 입력 |
| DeepSeek | API 키(`DEEPSEEK_API_KEY`), `https://api.deepseek.com` | deepseek-v4-pro(추천)·직접 입력 |
| xAI | API 키(`XAI_API_KEY`), `https://api.x.ai/v1` | grok-4.5(추천)·직접 입력 |

- Cursor·GitHub Copilot·Qwen·opencode·Amp·Grok 연결은 아직 **실험적**입니다.\
  동작하지 않으면 이슈로 알려 주세요.

- **자동**이면 Anthropic → Google → OpenAI → Ollama → 호환 서버 → OpenCode Go → OpenRouter → DeepSeek → xAI 순서로, 준비된 것을 사용합니다.

- 데스크톱 앱에 저장한 API 키는 운영체제 키체인(맥 키체인, 윈도우 DPAPI, 리눅스 비밀번호 저장소)으로 암호화해 따로 보관합니다.\
  화면에는 끝 네 글자만 보여 줍니다.\
  키체인이 없는 리눅스나 브라우저 모드에서는 환경 변수로 넣어 주세요.\
  셸 설정 파일(`~/.zshrc` 등)에 넣어 둔 키도 앱이 읽어 옵니다.

- 경기 화면 위쪽의 **AI 해설** 버튼을 누르면 그 경기의 결정적 장면부터 해설이 붙습니다.\
  매번 누르기 번거롭다면 **새 경기에서 자동으로 켜기**를 켜세요.

- **경기당 해설 한도**는 10·20·50·100 또는 무제한입니다.\
  한도를 넘거나 연결이 안 되면 해설은 정해진 문구로 나오고, 배움 카드와 나머지 기능은 그대로 동작합니다.

Claude Code 로그인(하이쿠)으로는 장면 하나에 20~40초, Claude Code가 보고하는 비용 기준으로 약 $0.03~0.07이 듭니다(첫 호출은 더 듭니다).\
Claude Code가 자체 지침을 함께 보내기 때문에 API 키로 직접 부르는 것보다 무겁습니다.\
Ollama는 무료입니다.

## 개인정보

- 데스크톱 앱은 웹서버를 열지 않습니다.\
  화면과 중계 엔진이 앱 안에서 직접 통신합니다.

- 브라우저 모드(`node bin/coding-live.mjs`)의 서버는 `127.0.0.1`에서만 열립니다.\
  다른 호스트 이름으로 온 요청과 출처가 다른 쓰기 요청은 거절합니다.

- 세션 기록은 이 컴퓨터 밖으로 나가지 않습니다.\
  단, 해설 마이크를 켜면 결정적 장면의 요약(최근 자막과 선수의 말 일부)이 선택한 프로바이더로 전달됩니다.\
  Ollama를 고르면 이 컴퓨터 안에서만 처리됩니다.

- 앱에 저장한 API 키는 운영체제 키체인으로 암호화해 `secrets.json`에 따로 두며, 화면으로는 보내지 않습니다.
